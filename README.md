# Projeto-Power-BI-Kaggle

Dashboard interativo de análise de dados desenvolvido em Power BI utilizando um dataset público do Kaggle.

🔗 **Link do dataset:** [Acesso ao dataset no Kaggle](https://www.kaggle.com/datasets/ahmadalijamali/dataset)

## Tecnologias e Funcionalidades
* **Ferramenta:** Power BI (Modelagem de dados e construção de layout visual).
* **Filtros Dinâmicos:** Segmentação interativa por Países e Intervalo de Datas.
* **Métricas Analisadas:** Quantidade vendida por produto, comportamento temporal por país e distribuição por faixa etária.
